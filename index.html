Ohrbob Logo Component

A highly configurable logo component that scales with font-size and supports multiple layouts.

Audio Widget Component

The <audio-widget> is a custom web component that docks to the bottom of the screen (position: fixed). In this showcase, we use the .audio-widget-inline utility class to embed it statically within the documentation flow.

Desktop View (Default)
<audio-widget 
    station="Radio 1"
    track="Cosmic Journey"
    artist="Space Explorer"
    cover="images/cover.png">
</audio-widget>
Mobile View

We apply .audio-widget-mobile here to force the mobile breakpoint styles for the showcase.

<!-- On screens < 768px, this layout is automatically applied. -->
<audio-widget 
    station="Radio 1"
    track="Cosmic Journey"
    artist="Space Explorer"
    cover="images/cover.png">
</audio-widget>

Audio Widget

The <audio-widget> is a custom web component styled as a glass panel with a frosted glass edge. It's a full-width player bar docked to the bottom of the viewport. Here is the code structure used for it:

<audio-widget 
    station="My Station" 
    track="Track Name" 
    artist="Artist"
    cover="image-url.jpg">
</audio-widget>

<script>
    const widget = document.querySelector('audio-widget');
    widget.addEventListener('play', () => console.log('Playing...'));
    widget.addEventListener('pause', () => console.log('Paused.'));
    widget.addEventListener('forward', () => console.log('Next track'));
    widget.addEventListener('back', () => console.log('Previous track'));
    widget.addEventListener('settings', () => console.log('Settings'));
</script>
